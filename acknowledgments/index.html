Technology​

The website is powered by Docusaurus, TypeScript and KaTeX.

Large language models assisted in many tasks, including implementation of user interfaces and translation of code from other programming languages. These tools include ChatGPT, Codex, Claude.ai, Claude Code, and GitHub Copilot.
