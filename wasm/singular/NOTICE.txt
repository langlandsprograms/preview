Singular WebAssembly engine for the GL(n) ABV calculator
======================================================

Singular.js, Singular.wasm, and Singular.data are unmodified assets from:
  https://singular-in-browser.pages.dev/engine/

The upstream engine-manifest.json is included verbatim. All three assets have
been verified against its SHA-256 hashes. Its build date is 2026-07-01, and the
engine reports system("version") = 44105 (Singular 4.4.1, patch 5).
The manifest identifies Emscripten 3.1.23. It does not record the Singular git
revision; we do not claim that the downloaded binaries were rebuilt locally.

The upstream build workflow checks out Singular, overlays Singular-in-browser
into emscripten/, then runs web-workbench/scripts/build-full-wasm.sh.
The companion singular-wasm-build.sh specifies and downloads the arithmetic
dependencies and their sources (GMP, MPFR, FLINT, NTL, cddlib, and Normaliz).
Retain their licenses when rebuilding or redistributing the engine.

Local integration:
  worker.js is the application's batch-only browser adapter. It uses no
  SharedArrayBuffer, cross-origin isolation headers, remote computation, or
  interactive terminal. The page downloads the three assets and compiles the
  WebAssembly module once, caching them across batches and packet computations.
  Each CLI batch runs in a fresh disposable worker with independent interpreter
  state. Its module is instantiated from the compiled cache; library data and
  the runtime are supplied from memory. Cancellation terminates the active
  workers without discarding the reusable assets. The application itself is
  not a port of Macaulay2.

Verify the sizes and SHA-256 hashes of the three engine assets against
engine-manifest.json. Replacement downloads from the upstream engine URL
must match these pinned hashes before replacing any asset. Updating the
engine requires updating the manifest and rerunning the native and browser
regressions; do not mix files from different engine builds.
